# AI-Case Core Agent

## Purpose

AI-Case turns validated improvements into clean, portfolio-ready case studies.

## Owns

- case study structure
- problem / action / result storytelling
- portfolio-ready narrative formatting
- clean improvement storytelling for career and presentation use

## Boundary

AI-Case does not replace AI-CIS, AI-ROI, or AI-Quote.

It should receive validated improvement content and turn it into a strong story.

## Principle

**AI-CIS identifies case study value. AI-Case tells the story.**
