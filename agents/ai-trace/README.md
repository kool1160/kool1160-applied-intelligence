# AI-Trace Core Agent

## Purpose

AI-Trace handles trace logging, summaries, patterns, escalations, and dashboard visibility inside the Applied Intelligence ecosystem.

## Owns

- trace logs
- trace summaries
- recurring pattern visibility
- escalation signals
- dashboard outputs

## Boundary

AI-Trace shows the picture clearly, but does not replace AI-CIS, corrective ownership, or ROI logic.

## Principle

**AI-Trace shows the picture clearly. AI-CIS fixes what the picture reveals.**
