# AI-Quote Core Agent

## Purpose

AI-Quote handles quoting and estimating inside the Applied Intelligence ecosystem.

## Owns

- estimating logic
- labor modeling
- weld and grind time framing
- flow-aware quoting
- fixture-aware quoting support

## Boundary

AI-Quote must stay focused on estimating and pricing logic.

It must not replace AI-CIS, AI-ROI, or AI-RMA.

## Principle

**AI-Quote prices the work clearly.**
