# Applied Intelligence Website

This folder contains the public-facing website shell for Applied Intelligence.

## Purpose

The website presents the Applied Intelligence ecosystem as a premium public framework surface.

It should:
- present the parent ecosystem clearly
- explain the role of the top-tier systems
- align visually with the flagship app experience
- stay cleaner and more narrative than the operating interface

## Core boundary

- website = public-facing framework shell
- app = operating interface

## Current website status

- current website pass: V12
- build type: static HTML / CSS / JS
- current key pages:
  - Home
  - Framework
  - AI-Connect
  - AI-Trace
  - Agents
  - About
  - Contact

## Design direction

- dark navy premium foundation
- strong headline hierarchy
- rounded premium card system
- newer liquid-glass / translucent chrome in navigation and dock areas
- cleaner content surfaces with restrained glow
- same ecosystem feel as the app without cloning app screens directly

## Source alignment

The website should stay aligned to the master ecosystem source under `shared/source/` and the website bundle under `core/bundles/applied-intelligence-website-source.json`.

## Current focus

The current stage is polish, not reinvention.

Priority areas:
- glass/chrome refinement
- spacing consistency
- stronger lower-page composition
- tighter copy edits
- responsive refinement for mobile while preserving the premium feel
