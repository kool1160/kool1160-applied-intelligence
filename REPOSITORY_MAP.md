# Working rules

1. **A repository can be successful without becoming a product.** Learning experiments may stop when their learning objective is complete.
2. **Production/family projects are not counted as AI-career project sprawl.** They are maintained because somebody actually uses them.
3. **One active AI-learning flagship at a time.** Other ideas may be documented but should not silently become active builds.
4. **Held is a valid state.** Held means intentionally preserved, not failed.
5. **Portfolio-complete is different from commercially launched.** A technically strong project may be frozen after it proves the intended capability.
6. **Before restarting an old repository, define the new skill, smallest useful scope, evidence of learning, and stop condition.**

This map should be updated whenever a project's lifecycle changes so GitHub remains understandable without relying on memory or old chat history.
